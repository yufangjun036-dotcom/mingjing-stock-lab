# 明镜选股｜受限研究演示

面向希望把自然语言选股意图变为可核验条件的投资研究用户。Python + Streamlit 界面，扶摇真实估值数据，OpenAI 解析意图，Python 确定性筛选。

**在线演示：https://mingjing-stock-lab-backup.onrender.com/ 。已完成一次云端 AI 解析、真实取数与同快照比较验收；免费实例休眠后首次打开需等待唤醒。** 已接通 PE TTM / PB MRQ、收入同比、归母净利同比、毛利率、60 日年化波动率、条件编辑、冲突校验、三态结果、逐字段证据、同快照比较、JSON 保存载入。股票池只有六只明确列出的开发样本，不代表全市场。财务累计口径已用茅台公告抽样确认，逐次取数做金额复算与供应商指标交叉核验；不声称每家公司均已逐份公告审计。

## 本地启动

已验证 Python 3.13。

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/streamlit run app.py --server.address 127.0.0.1
```

服务端设置 `FUYAO_API_KEY` 和 `OPENAI_API_KEY`。本地可分别放入被 Git 忽略的 `.env.fuyao`、`.env.local`；不要上传真实密钥。环境变量优先。可选 `APP_CA_FILE` 指定可信证书，`OPENAI_PROXY` 指定模型专用代理。云端不要照搬本地代理。应用始终验证 HTTPS 证书。

## 使用

1. 输入明确条件，例如“市盈率大于 0 且小于 25 倍”。示例阈值不是投资推荐。
2. AI 给出草案及假设。未支持、待澄清和拒绝事项不能直接执行；修改原意图重新解析，或显式切换为独立手动方案。
3. 检查/修改表格，勾选确认，再获取真实数据。任何接口失败均显式提示，不生成模拟结果。
4. 查看每只股票的条件状态、原字段、原值、来源、请求 ID 和时间。
5. 修改条件后使用原快照重算比较，避免把行情变化误当条件影响。新增指标不在原快照时，点击“补齐新增指标”统一取数并重算两方案。保存的 JSON 仅包含方案。

## AI、数据和算法边界

模型 `gpt-4.1-mini` 只翻译条件，使用结构化输出；不生成财务数值，不决定入选，不输出买卖建议。模糊意图不会悄悄变为已确认阈值。结构化输出仍可能语义出错，需要用户检查和后端白名单校验。

扶摇 API 是当前唯一金融数据源，未接入 iFinD。估值字段由供应商提供，倍为单位；批次时间不等于逐股成交时间，估值分母未独立重算。负 PE 保留原值，“便宜”不自动等于亏损公司的负 PE。缺失不是零；任一条件不满足则排除，同时仍保留未知项。

## 受限演示保护

每会话每分钟2次外部操作、单实例每日100次、单进程最多2操作并发；失败尝试计数，原快照比较不计数。一次取数可包含多次HTTP请求。`USAGE_DB_PATH`可指定持久化SQLite文件，默认`.runtime/usage.sqlite3`。本地计数丢失或多副本部署无法保证跨实例日上限，不是账户金额上限。详情及后续55项回归、干净环境/留出题记录见 docs/11_留出评测环境复现与演示限额验收.md。

## 新手澄清入口

新增“不懂指标？从三个常见想法开始”：收入/利润、估值、波动三组显式选择，附白话解释及原意对照。没有默认答案，教学阈值不代表投资标准；未支持的同行比较不能直接执行。生成后仍需检查条件并确认。它是确定性引导模板，不冒充多轮模型对话，详见docs/13_新手澄清流程与验收.md。
