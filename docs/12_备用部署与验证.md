# 备用部署与验证

## 当前状态

2026-11-04：Render 备用部署配置已准备，本地验证通过；尚未创建 Render 服务，尚无已验收的备用公网 URL。不能把本地测试结果当成云端上线结果。

## 文件与作用

- `render.yaml`：Python Web Service 蓝图，明确使用 free 实例，配置构建、启动和健康检查。
- `.python-version`：指定 Python 3.13 系列，补丁版本由平台选择。
- `deploy/requirements-render.txt`：从原锁定依赖复制，只将 PyArrow 26.0.1 改为 24.0.0。依据是用户提供的 Streamlit 构建日志已自动进行同样替换；此调整不被宣称能解决网络超时。
- `scripts/start_web.py`：读取并校验 PORT，监听 0.0.0.0，启动现有 app.py，保留默认安全配置。

## Render 创建参数

仓库：https://github.com/yufangjun036-dotcom/mingjing-stock-lab
分支：main
语言：Python
构建：`pip install -r deploy/requirements-render.txt`
启动：`python scripts/start_web.py`
健康检查：`/_stcore/health`
实例：Free；不要未经确认改为付费。

可通过 Blueprint 导入 render.yaml；或新建 Web Service 使用上述参数。
密钥变量为 OPENAI_API_KEY、FUYAO_API_KEY。蓝图不包含真实值；保存到新平台前须得到用户对具体密钥和目的地的确认。不要上传 .env 文件，不要复制本机 OPENAI_PROXY 或 APP_CA_FILE 路径。

## 已知限制

Render Free 会休眠，资源有限，不适合作为持续多人生产服务承诺。实例临时磁盘可能在重建时丢失，现有 SQLite 日额度不是跨重建、跨实例的强制总预算。备用部署仅替换托管环境，不扩充六只股票池，不改变核心筛选逻辑；不能保证换平台就消除当前网络问题。
