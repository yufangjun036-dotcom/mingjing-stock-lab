# 首次使用任务：实现与验证

用户反馈：三个概念解释和选择卡仍然无法让新手独立完成任务。因此首页改为明确任务“哪些公司的收入和利润比去年同期增加了？”，先执行一个完整研究任务。

## 流程
首页展示六家公司、2026年1–9月对比2025年同期、两项同比均大于0的规则。用户点击“开始查看”即确认这项固定任务，不要求填写数字。Python复用原有真实数据获取、质量检查及筛选引擎；此任务模板不调用模型，不冒充AI自主判断。自由文本AI解析和专业条件编辑保留在默认折叠的自定义研究入口。

结果表逐家公司展示收入变化、利润变化、符合/不符合/未知。显示值保留两位，计算沿用未舍入数值。数据缺失不显示为0，持平不称增长，失败保留旧结果并明确提示。只要一项已不满足，该公司不入选，同时未知原因仍展示。

“如果只要求收入增加，结果会怎样？”按钮明确移除利润约束，复用同一快照，展示新增符合公司，并说明不代表利润增长。详细原字段和来源在折叠证据区可查。任务与专业方案使用不同会话键，共用调用额度保护。

## 文件职责
- core/beginner_task.py：growth_strategy构建两种固定策略；plain_growth解释有效值与缺失；beginner_rows对应公司结果表。
- ui/beginner_task_panel.py：render_beginner_task负责明确触发真实取数、保留失败状态、同快照比较与结果展示。
- app.py：先渲染任务，再折叠专业流程；ui/layout.py更新首页和侧栏指引。
- tests/test_beginner_task.py：构造正增长、下降、持平和缺失，检查加载不联网、点击才联网、比较不联网、失败不覆盖旧结果。
