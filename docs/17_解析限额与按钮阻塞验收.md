# 解析限额与按钮阻塞验收

## 查明事实
当前Chrome页面实际存在八条条件，同时模型输出了重复的报告期澄清和缺失处理澄清，导致blocked状态，确认复选框不会越过此状态。另发现解析异常只保留blocked、不保留错误说明，重跑后可能形成无解释灰按钮。AI解析和取数各占一次外部操作；第一次限额的原始点击序列未还原，不能断言计数器错误。

## 修复
明确提示模型：产品固定报告期、缺失值政策不是待追问事项，用户已给出的条件不能重复澄清；真正未支持的内容仍阻止执行。相同会话重复提交相同成功输入复用草案；空输入不计额度。解析错误持续展示，失败后旧表不能冒充新需求，显式恢复此前草案必须重新确认。按钮旁显示阻塞原因。限额提示包含已用次数、预计剩余等待秒数和无需重解析说明；保留用户确认的2次/分钟、100次/日与并发2限制。
