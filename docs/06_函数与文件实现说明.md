# 文件与函数实现说明

版本 v0.2｜2026-11-04。基于当前 Python 源码逐项核对；参数默认值按实际签名保留。下列函数均有中文说明，流程注明返回值和失败分支。测试函数由 tests/ 中的中文用例说明及 04 验收记录管理。

## app.py

明镜选股入口：真实数据原型，所有执行由显式按钮触发。

### `main()`

渲染意图、可编辑条件、结果和同快照比较。

处理流程与输出：初始化页面和配置 → 恢复会话类型 → 解析提交/处理导入 → 编辑条件并校验 → 用户确认后按按钮选择新取数、原快照或联合比较 → 保存成功结果 → 展示旧结果提示、结果及比较。异常显示安全提示，finally 关闭客户端；输出为页面和 session_state。

## config.py

服务端配置：环境变量优先，本地密钥文件仅补充缺项。

- 类型 `Settings`：隐藏密钥的对象表示，避免日志意外泄露。

### `load_settings()`

从环境或本地文件读取配置；不输出秘密值。

处理流程与输出：读取 .env.local/.env.fuyao 且不覆盖已有环境 → 读取两种 API Key 和可选 CA → 返回隐藏密钥 repr 的 Settings；不打印配置。

### `build_ssl_context(settings)`

使用有效 CA 并保留证书与主机名校验；兼容本地和云端。

处理流程与输出：选择显式 CA 或 certifi → 创建启用证书/主机名校验的 SSLContext；无效 CA 由 SSL/文件异常报告，不降级为关闭验证。

## core/condition_validator.py

对 AND 条件进行白名单检查及严格开闭区间冲突识别。

### `detect_conflicts(conditions)`

合并同指标上下界；等值约束同时作为闭区间上下界。

处理流程与输出：按指标分组 → 将 = 同时作为闭上下界 → 选择最严格上下界 → 判断倒置或相等但开区间 → 返回包含条件 ID 的错误列表；不调用数据源。

### `validate_strategy(strategy: Strategy)`

拒绝未知、未启用及相互矛盾条件；返回可直接使用的方案。

处理流程与输出：遍历条件查启用白名单 → detect_conflicts → 有冲突抛 ValueError → 返回原不可变方案；版本/数量由模型负责。

## core/intent_parser.py

自然语言转条件草案；结构化输出仍需服务器校验和用户确认。

- 类型 `DraftCondition`：模型输出只接受白名单字段格式，阈值使用字符串避免浮点误差。

- 类型 `IntentDraft`：保留所有未解决事项；不得只执行可解析的部分。

### `build_intent_prompt()`

向模型提供实际启用指标、单位、能力边界和拒绝规则。

处理流程与输出：读取启用指标的中文名称和单位 → 拼接 AND、澄清、拒绝、禁止编造和固定报告期规则 → 返回系统提示字符串。

### `draft_to_strategy(draft)`

有待澄清或不支持事项即阻止执行；不悄悄丢弃原始意图。

处理流程与输出：有 clarification/unsupported/refusal 则抛 ValueError → 顺序编号草案条件 → 构造 Strategy → 调用 validate_strategy → 返回合法方案；页面另有 blocked 闸门。

### `parse_intent(text, settings)`

一次点击对应一次真实调用；失败显式报错，不用假结果替代。

处理流程与输出：检查文本长度和配置 → 建立带 CA/可选本地代理的客户端 → 调用 Responses parse → 检查 completed、条件数、条件结构和启用白名单 → 返回 IntentDraft；API/结构失败转安全 ValueError。

## core/metrics.py

服务器维护的指标白名单；财务累计口径有公告样本核验，逐股数据仍执行质量检查。

- 类型 `MetricDefinition`：指标名称、单位、依赖与启用门槛。

### `get_metric(metric_id)`

按白名单查找指标；未知指标报错，不动态执行公式。

处理流程与输出：在固定注册表按 ID 查找 → 未知 ID 抛 ValueError → 返回指标定义，不从用户输入生成公式。

### `list_enabled_metrics()`

仅返回本次实现已接入且允许执行的指标。

处理流程与输出：过滤注册表 enabled 标记 → 返回 ID 到定义的字典，供解析器和 UI 共用。

## core/result_explainer.py

仅根据引擎证据生成解释，不让语言模型编造入选理由。

### `explain_condition(evaluation)`

展示实际值、阈值和质量状态；所有单位来自服务器字典。

处理流程与输出：查询名称和单位 → 生成阈值描述 → unknown 显示原因；pass/fail 显示实际值四位小数并注明比较未舍入 → 返回中文字符串。

### `explain_stock(row)`

保留失败及未知明细，不生成买卖建议。

处理流程与输出：映射总体状态 → 拼接全部逐条件解释 → 返回中文文本，不生成买卖建议。

## core/schemas.py

不可变领域契约；使用十进制数，禁止布尔值和非有限数字。

- 类型 `Model`：所有模型禁止额外字段，避免未知输入被静默忽略。

- 类型 `Condition`：一条可执行条件；指标合法性由服务器字典再次检查。

- 类型 `Strategy`：版本化方案；报告期和演示股票池显式固定。

- 类型 `Evidence`：可公开的证据定位；永不存储请求头或密钥。

- 类型 `MetricValue`：只有 valid 数值可参与比较，其余状态保留具体原因。

- 类型 `StockRecord`：以元组保存指标，避免嵌套字典修改既有快照。

- 类型 `DatasetSnapshot`：一次取数形成的不可变快照；失败股票也必须保留。

- 类型 `ConditionEvaluation`：确定性计算产生的逐条件结论。

- 类型 `StockEvaluation`：股票总体状态以及全部条件明细。

- 类型 `ScreeningResult`：结果绑定当时的条件和数据快照，而非界面草案。

### `finite_number(cls, value)`

拒绝 bool、空值和 NaN/Infinity；保留未舍入的阈值。

处理流程与输出：拒绝 bool/None → Decimal(str(value)) → 检查有限性、绝对值和有效数字数 → 返回 Decimal；非法输入抛 ValueError。

### `unique_ids(self)`

条件 ID 必须唯一，保证解释可以定位到条件。

处理流程与输出：收集所有条件 ID → 比较去重后长度 → 重复抛 ValueError，否则返回模型自身。

### `valid_value(self)`

防止把缺失值或无限值标为正常数据。

处理流程与输出：检查非空数值有限 → quality=valid 时要求 value 非空 → 返回模型自身；不符合抛 ValueError。

## core/screening_engine.py

确定性筛选引擎：不调用 AI，不执行模型生成代码。

### `evaluate_condition(value, condition)`

质量不合格时返回 unknown，正常值使用未舍入 Decimal 比较。

处理流程与输出：默认 unknown → quality=valid 时由固定运算符映射比较未舍入值 → 返回含原条件与证据的 ConditionEvaluation。

### `evaluate_stock(stock, strategy)`

任一失败即排除；没有失败但存在未知时无法判断。

处理流程与输出：读取股票指标 → 缺指标构造 missing → 逐条件 evaluate_condition → fail 优先排除，否则 unknown，再否则 selected → 返回保留所有明细的 StockEvaluation。

### `screen(snapshot, strategy)`

校验范围后覆盖全部股票；结果 ID 同时绑定条件和快照。

处理流程与输出：校验方案 → 比较股票池和报告期 → 按代码排序逐股判断 → 快照 ID 加方案 JSON 做 SHA256 → 返回 ScreeningResult；范围不匹配抛 ValueError。

## data/normalizer.py

把原始字段转为带证据的指标，保留缺失与冲突。

### `parse_decimal(raw)`

有限数值转 Decimal；缺失或非法值返回 None，绝不填零。

处理流程与输出：None/bool 直接返回 None → 转 Decimal → 非有限或非法字符串返回 None → 否则返回数值；不填零。

### `compute_yoy(current, prior, evidence=(), verified=False)`

只有口径确认且前期基数大于零时才计算普通同比。

处理流程与输出：解析两值 → 未核验返回 unverified → 缺失返回 missing → 前期非正返回 not_applicable → 计算百分比并返回带证据 valid。

### `compute_gross_margin(revenue, costs, evidence=(), verified=False)`

按收入和成本计算毛利率；银行等缺成本时保持未知。

处理流程与输出：解析收入成本 → 检查 verified、缺失、收入正值 → 计算百分比 → 返回 MetricValue；不截断负毛利率。

### `compute_volatility(prices, trading_days, evidence=())`

输入为日期-价格对与已完成交易日清单；检查最后 61 日连续性。

处理流程与输出：选最后 61 个交易日 → 不足返回 missing → 检查价格重复 → 按日历对齐正价格 → 缺/非正返回 missing → 60 个收益率 stdev 年化 → 返回 MetricValue。

### `normalize_stock(code, envelope)`

按预定股票池合并估值数据；未返回、重复股票均显式标记。

处理流程与输出：按代码过滤估值行 → 重复标 conflict、缺值标 missing → 有效值再检查批次时效 → 创建每字段证据 → 返回含 PE/PB 的 StockRecord；名称缺失显示代码。

### `build_snapshot(records, created_at, source_errors=(), available_metrics=('pe_ttm', 'pb_mrq'), history_cutoff=None)`

内容、质量、取数时间共同生成快照标识；结果不可原地修改。

处理流程与输出：股票排序 → 序列化数值、证据、时间、可用指标和错误 → SHA256 → 返回元组构成的不可变 DatasetSnapshot。

### `source_evidence(envelope, field, raw, unit, report=None, formula=None, report_date=None)`

统一保留请求参数、原字段、时间和单位，不包含鉴权头。

处理流程与输出：把响应封装参数排序转字符串元组 → 保存原字段/原值、单位、报告期、公式与供应商日期 → 返回 Evidence，不包含请求头。

### `select_report_pair(rows, report)`

准确选择本年与上年同季度；重复记录、币种和期间冲突报错。

处理流程与输出：解析年/季度 → 匹配本年和上年同季度 → 缺任一期返回 (None,None) → 重复、币种、期间、期末异常抛 ValueError → 返回两行；当前仅支持 Q3 路径。

### `normalize_financials(code, income, indicators, report)`

金额复算并与同源指标交叉验证；原文核验为样本验证而非逐股审计。

处理流程与输出：选同期报表并核对代码 → 验证指标响应范围 → 建指标索引 → 每项构造原金额证据并复算 → 缺核对值标 unverified，重复/差异超容差标 conflict → 返回三指标字典。

### `normalize_history(history, calendar, cutoff)`

验证日历和复权元数据，保留 61 个价格及日历输入证据。

处理流程与输出：核对 forward/1d → 校验日历日期、重复、截止日 → 解析价格并检查日历成员关系 → 创建日历和 61 日原值证据 → compute_volatility → 附窗口说明返回 MetricValue。

## data/provider.py

扶摇 HTTPS 客户端：业务错误和传输失败均不能伪装成空结果。

- 类型 `ProviderError`：只携带安全的错误类别与消息，不保留密钥或完整响应。

- 类型 `FuyaoClient`：固定域名、有限超时；当前版本不自动重试，失败交由用户重试。

### `__init__(self, category, message)`

构造供页面展示的安全异常。

处理流程与输出：保存 category，安全 message 交给异常基类；不保存响应体或密钥。

### `__init__(self, settings, transport=None)`

依赖注入 transport 供离线测试；真实请求使用可信 CA。

处理流程与输出：缺少扶摇密钥时抛配置错误 → 创建固定 base_url、15 秒超时、可信 CA 的 HTTPX 客户端；transport 可注入测试替身。

### `close(self)`

释放连接池。

处理流程与输出：关闭 HTTPX 连接池；无业务返回值。

### `request_json(self, path, params)`

校验 HTTP、JSON、业务码和数据结构，并附取数时间。

处理流程与输出：拒绝未开放端点 → GET → 分类超时/网络/HTTP/鉴权/限流 → 解析 JSON → 校验整数 code=0 与数据列表结构 → 返回 data、request_id、retrieved_at、endpoint、params 字典；失败抛去敏 ProviderError。

### `get_valuations(self, codes)`

每批 1–100 个标准 A 股代码；去重后请求估值快照。

处理流程与输出：去重代码 → 验证 1–100 个标准沪深代码 → 合并逗号参数 → request_json 估值端点 → 返回响应封装。

### `check_code(self, code)`

只接受标准沪深股票代码。

处理流程与输出：正则验证六位代码和 SH/SZ 后缀；非法抛 ValueError，成功无返回值。

### `get_income(self, code)`

按季度末取最近八期累计利润表；口径见数据核验记录。

处理流程与输出：检查代码 → 固定 quarterly/limit=8 → 请求利润表 → 返回封装；累计语义在标准化层处理。

### `get_indicators(self, code, report)`

仅查询固定报告期，用于与金额复算值交叉检查。

处理流程与输出：检查代码 → 只允许 2026-3 → 请求财务指标 → 返回封装；其它报告期抛 ValueError。

### `get_calendar(self, start, end)`

查询真实交易日历，不用工作日猜测节假日。

处理流程与输出：拒绝起始晚于结束 → 转 yyyyMMdd → 请求交易日历 → 返回封装。

### `get_history(self, code, start, end)`

前复权日线；区间端点以北京时间毫秒表达。

处理流程与输出：检查代码和范围 → 北京时间起日零点/止日末尾转毫秒 → 固定 1d/forward → 请求并返回封装。

## services/screening_service.py

按需取数、保存不可变快照，并在同一数据上比较条件变化。

### `required_sources(strategy)`

按指标收集依赖，避免估值策略也请求六份历史和财报。

处理流程与输出：从条件 ID 集合推导 valuations 基础与财务/历史依赖 → 返回端点类别集合；辅助函数，当前 fetch_snapshot 自身按指标集合执行依赖。

### `fetch_snapshot(client, strategy, extra_strategy=None, now=None)`

最大两个股票任务并发；部分失败保留所有股票及安全错误。

处理流程与输出：校验两方案 → 合并指标和固定股票池 → 确定北京时间昨天与回溯 220 日 → 请求估值/必要日历 → 两线程运行 fetch_stock → 汇总所有股票和错误 → 返回新快照。

### `fetch_stock(code)`

单股票任务按顺序请求，避免把端点并发扩大到线程数之外。

处理流程与输出：估值标准化 → 顺序请求所需财务及核对指标 → 失败保留未知及错误 → 必要时请求历史并核对代码 → 返回 StockRecord 与本股错误列表；这是 fetch_snapshot 内部函数。

### `run_screening(client, strategy, snapshot=None)`

快照不包含新增指标时显式报错，不偷偷混入新数据。

处理流程与输出：校验方案 → 无传入快照则取数 → 新指标不在 available_metrics 时抛 ValueError → screen → 返回 (snapshot,result)。

### `compare_results(base, new)`

拒绝跨快照比较，返回每只发生变化的股票前后状态。

处理流程与输出：检查相同快照、股票池、报告期和股票代码集合 → 按代码比较状态 → 仅返回变化项 thscode/before/after；不一致抛 ValueError。

### `compare_with_new_snapshot(client, baseline, strategy)`

以 A/B 联合依赖取一次新数据，再重算两方案后比较。

处理流程与输出：取基准和新方案指标并集快照 → 在新快照分别 screen → compare_results → 返回快照、重算基准、新结果、变化列表。

## services/session_state.py

恢复会话中的领域对象，兼容 Streamlit 热更新后的 Python 类重载。

### `rehydrate_state(state)`

经 JSON 契约重建旧实例，避免旧类对象与新校验器类型不兼容。

处理流程与输出：遍历已知快照/结果/草案键 → 对有 model_dump_json 的非空值序列化 → 通过当前模型解析重建 → 原位更新会话；不联网。

## services/strategy_io.py

版本化方案导入导出，不联网、不执行上传文件中的代码。

### `export_strategy(strategy)`

只导出条件白名单字段，无密钥和金融原始响应。

处理流程与输出：Strategy JSON 序列化（Decimal 为字符串）→ UTF-8 bytes；仅输出方案字段。

### `import_strategy(content)`

限制文件大小，严格校验后返回待用户确认的方案。

处理流程与输出：检查不超过 100 KB → 严格 JSON 模型解析 → validate_strategy → 返回待确认方案；不会取数或执行上传代码。

## ui/comparison_panel.py

方案变化展示：把引擎的状态代码转换为可读表格。

### `render_comparison(baseline, result, changes)`

展示同快照的两套条件和状态变化；不重新计算、不调用外部接口。

处理流程与输出：显示同快照说明 → 中文展示两套方案 → 无变化显示提示 → 有变化映射状态和股票名称展示表格 → 无业务返回。

## ui/condition_panel.py

用中文指标名称呈现条件，隔离页面表示与内部字段 ID。

### `render_condition_editor(conditions, revision)`

中文展示单位；返回白名单字段，交给服务器执行结构校验。

处理流程与输出：启用指标生成中文标签与反向 ID 映射 → 以 revision 作为编辑器键 → 渲染可增删行的表格 → 反向转换 → 返回待校验条件字典列表。

## ui/layout.py

页面导航与范围说明；与数据计算分离，便于调整展示方式。

### `render_header()`

呈现产品入口和固定研究范围；完整口径放在侧栏以减少主流程干扰。

处理流程与输出：渲染标题、固定样本范围 → 侧栏展示流程和折叠口径 → 无业务返回，不联网。

### `condition_rows(strategy)`

将方案转为中文表格；仅改变展示，不更改原始阈值及运算符。

处理流程与输出：遍历方案条件 → 查询指标中文名和单位 → 保留 operator 与原始阈值字符串 → 返回中文表格行。

## ui/results_panel.py

结果展示和逐字段证据查看。

### `render_results(result, snapshot)`

展示绑定条件和快照时间，防止草案变化误标旧结果。

处理流程与输出：显示快照/截止日/错误 → 三态计数和全池表格 → 展开实际条件 → 逐股票逐条件解释 → 原字段表和按请求去重元数据 → 无业务返回。

## 非函数文件与辅助脚本

## services/usage_guard.py（新增）

UsageLimitError：安全阻断异常。UsageGuard.__init__(path,daily,per_minute,concurrent,clock)：初始化SQLite日计数和分钟事件表及信号量。reserve(session)：占槽→SQLite事务核对分钟/日额度→写入计数→执行调用→finally释放；超额与存储异常抛安全错误。_cached_guard(path)：缓存构造，需在初始化锁内使用。get_usage_guard()：读取配置路径，在锁内取得共享对象；初始化失败拒绝调用。

app.main新增随机会话ID，解析和新取数包裹reserve，原快照比较绕过外部调用额度。以上适用单实例/单进程，详细边界见11。
